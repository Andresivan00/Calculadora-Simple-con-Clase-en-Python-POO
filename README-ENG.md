# Simple Calculator with Classes in Python (OOP)

Educational and 100% functional example of **Object-Oriented Programming** that creates a `Calculator` class to perform the 4 basic operations: **addition, subtraction, multiplication, and division**.

### What this code does exactly
- Defines a `Calculator` class that receives two numbers when created
- Saves the numbers as internal attributes (`_a` and `_b`)
- Has 4 methods:
  - `.add()` → returns a + b
  - `.subtract()` → returns a − b
  - `.multiply()` → returns a × b
  - `.divide()` → returns a ÷ b
- Creates an object with values 5 and 8
- Displays the results of all operations
